
# SCL/SDA Controller

## Overview

The **SCL/SDA Controller** is a key module of the I2C Master Controller responsible for controlling the two communication lines of the I2C bus:

- **SCL (Serial Clock)**
- **SDA (Serial Data)**

This module generates the **START** and **STOP** conditions required by the I2C protocol and controls the SCL signal during data transmission.

---

## Objective

- Generate the I2C START condition.
- Generate the I2C STOP condition.
- Control the SCL signal during communication.
- Interface with the I2C Master FSM.

---

## Features

- Active-high synchronous reset
- START condition generation
- STOP condition generation
- SCL control using divided clock (`scl_tick`)
- Synthesizable Verilog HDL
- Compatible with Xilinx Vivado

| stop | 1 | Generates STOP condition |
| scl_tick | 1 | Clock generated by the Clock Divider |

---

| Signal | Width | Description |
|---------|------|-------------|
| scl | 1 | Serial Clock output |
| sda | 1 | Serial Data output |

---

# Working Principle

The controller operates as follows:

1. After reset, both **SCL** and **SDA** remain HIGH, representing the idle state of the I2C bus.
2. When the **start** signal is asserted:
   - SCL remains HIGH.
   - SDA transitions from HIGH to LOW, creating the **START** condition.
3. During data transmission:
   - SCL follows the `scl_tick` signal generated by the Clock Divider.
4. When the **stop** signal is asserted:
   - SCL remains HIGH.
   - SDA transitions from LOW to HIGH, creating the **STOP** condition.
