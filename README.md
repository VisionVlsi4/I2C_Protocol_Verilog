# I2C Master Controller using Verilog HDL

## Project Overview

This project implements a **simplified I2C (Inter-Integrated Circuit) Master Controller** using **Verilog HDL**. The design follows a modular RTL architecture, where each functional block is implemented, verified individually, and then integrated into a top-level module.

The project demonstrates the fundamental operation of an I2C Master, including clock generation, serial data transmission, ACK detection, START/STOP condition generation, and finite state machine (FSM) based control.

---

## Objectives

- Design an I2C Master Controller using Verilog HDL.
- Understand the I2C communication protocol.
- Implement modular RTL design.
- Verify each module using behavioral simulation.
- Integrate all modules into a complete system.
- Simulate the design using Xilinx Vivado.

---

## I2C Protocol Overview

I2C (Inter-Integrated Circuit) is a synchronous serial communication protocol that uses only **two communication lines**:

- **SCL (Serial Clock)** – Generated by the Master.
- **SDA (Serial Data)** – Used for data transfer between Master and Slave.

### Communication Sequence

```
START
   ↓
Slave Address
   ↓
ACK
   ↓
Data Byte
   ↓
ACK
   ↓
STOP
```

# Modules

## 1. Clock Divider

Generates the slower **SCL clock** from the high-frequency system clock.

**Inputs**

- clk
- rst

**Output**

- scl_tick

---

## 2. Shift Register

Loads the parallel input data and shifts one bit at a time for serial transmission.

**Inputs**

- clk
- rst
- load
- shift
- data_in

**Outputs**

- serial_out
- data_out

---

## 3. Bit Counter

Counts the transmitted bits during communication.

**Inputs**

- clk
- rst
- enable

**Outputs**

- count
- done

---

## 4. ACK Detector

Checks whether the slave responds with an ACK or NACK.

**Inputs**

- clk
- rst
- ack_in
- check_ack

**Output**

- ack_received

---

## 5. SCL/SDA Controller

Generates the START and STOP conditions and controls the SCL and SDA signals.

**Inputs**

- clk
- rst
- start
- stop
- scl_tick

**Outputs**

- scl
- sda

---

## 6. I2C Master FSM

Controls the complete I2C transaction using a Finite State Machine.

### FSM States

```
+------+
| IDLE |
+------+
    |
    ▼
+-------+
| START |
+-------+
    |
    ▼
+-----------+
|SEND_ADDR  |
+-----------+
    |
    ▼
+------+
| ACK1 |
+------+
    |
    ▼
+-----------+
|SEND_DATA  |
+-----------+
    |
    ▼
+------+
| ACK2 |
+------+
    |
    ▼
+------+
| STOP |
+------+
    |
    ▼
+------+
| IDLE |
+------+
```
